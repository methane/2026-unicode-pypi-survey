# Attribution and source excerpts

This publication subset contains investigation text, compact factual datasets, analysis scripts and contextual excerpts from third-party package sources. It does not redistribute the full source corpus or downloaded distributions.

Every case identifies its package, frozen version, original source-distribution URL and SHA256, archive member path, member SHA256 and exact excerpt line range. A permanent repository link is included only when its source equivalence was verified. Source-distribution provenance remains available where a repository link could not be verified. These fields attribute each excerpt to its originating release.

Third-party excerpts retain their originating copyright and licensing terms; this report does not assign them a new blanket license. The exact release's source archive is the authoritative place to inspect its included license and copyright notices. No assertion is made that every package uses the same license. The excerpting policy retains contextual windows and states omitted ranges rather than copying whole long algorithms. A package/version index is provided in [cases/README.md](cases/README.md), and lifetime evidence names its sources independently.

The ranking is attributed to [hugovk/top-pypi-packages](https://github.com/hugovk/top-pypi-packages/tree/e6b5b398c1fcc783f593031f99bc2c772d64c6ef), with snapshot and generator provenance included in the data directory.

The canonical download and source-filter behavior is attributed to Victor Stinner's [`misc` scripts](https://github.com/vstinner/misc/tree/f1ba71b20c650f0e63920fe6f25292794c38f94a). These upstream scripts are referenced by immutable URL and hash. The portable scanner is an analysis adaptation; differences and reproducibility limits are documented in [scripts/README.md](scripts/README.md).

The new report and analysis code have no blanket redistribution license assigned in this prepared tree. Publishing the tree should retain these source attributions and the distinction between investigation material and third-party excerpts.
